Procedure:
1. Use this procedure only when prepare_table_append and execute_operation are available.
2. Discover the intended table and inspect its current schema. Resolve business ambiguity before preparing records. Read all schema pages needed to supply complete named records.
3. Supply literal values for every column. Copy each complete user-supplied text value, including all words, punctuation and identifiers. Do not shorten, paraphrase, translate or normalise it without explicit user instruction. Map values to schema columns without changing their meaning. Do not invent missing facts, currency rules or formulas. Formula-bearing tables are unsupported for appends.
4. Compare every proposed field with the user's request before calling prepare_table_append. Preserve numeric amounts as numbers and text identifiers as text; formatting is not a reason to change a value's type. If a required conversion or field boundary is unclear, ask before preparing. Call prepare_table_append with the checked records and table ID. The server supplies observed revisions and stores a retry reference. Preparation changes no cells, grants no approval and does not certify execution validation.
5. Call execute_operation with that reference. After an uncertain response, retry the same reference. Do not inspect and create a new append to recover an unknown outcome.
6. Identical records prepared against identical revisions share one reference. A distinct later append requires fresh inspection and clear user intent.
7. Report a write only from its committed receipt. A receipt is not proof that the proposal matches the user's request. If you discover a value mismatch after execution, disclose it; do not append a replacement row or claim the task is complete. State partial completion if later work fails. A committed append does not mean formulas recalculated or accounting invariants passed; preserve the receipt's stated limits.
8. Inspect again before further calculations or new writes on the changed sheet. If a proposal fails revision validation, review current evidence before preparing new work.
